**Actividad Final de Unidad. Glosario de conceptos**

1. Algoritmo
Definición: Un algoritmo es una serie de pasos ordenados que se siguen para resolver un problema o realizar una tarea. Es como una guía que indica qué hacer y en qué orden.
Ejemplo: Para preparar un café, primero se calienta el agua, después se coloca el café en una taza, se agrega el agua y finalmente se mezcla.
Fuente consultada: Elaboración propia.

2. Programa
Definición: Un programa es un conjunto de instrucciones que una computadora puede ejecutar para realizar una tarea específica.
Ejemplo: Una calculadora es un programa que recibe números y operaciones y después muestra el resultado.
Fuente consultada: Elaboración propia.

3. Código fuente
Definición: El código fuente es el conjunto de instrucciones escritas por un programador utilizando un lenguaje de programación. Posteriormente puede ser interpretado o compilado para que la computadora pueda ejecutarlo.
Ejemplo: En Python, print("Hola") forma parte del código fuente de un programa que muestra la palabra “Hola”.
Fuente consultada: Elaboración propia.

4. Lenguaje de programación
Definición: Es un lenguaje que permite a las personas escribir instrucciones de una manera que pueda ser interpretada o traducida para que una computadora realice determinadas acciones.
Ejemplo: Python, Java, C++ y JavaScript son lenguajes de programación utilizados para crear diferentes tipos de programas.
Fuente consultada: Elaboración propia.

5. Sintaxis
Definición: La sintaxis son las reglas que indican cómo deben escribirse correctamente las instrucciones de un lenguaje de programación. Si no se respetan, el programa puede producir errores.
Ejemplo: En Python, escribir print("Hola") es correcto, mientras que utilizar una estructura que Python no reconoce puede provocar un error de sintaxis.
Fuente consultada: Elaboración propia.

6. Variable
Definición: Una variable es un espacio donde un programa puede guardar un dato que puede cambiar mientras el programa está funcionando.
Ejemplo: edad = 18. Después, cuando la persona cumple años, la variable puede cambiar a edad = 19.
Fuente consultada: Elaboración propia.

7. Constante
Definición: Una constante es un valor que se establece para mantenerse sin cambios durante la ejecución de un programa.
Ejemplo: En un programa se puede definir PI = 3.14159 para utilizar ese valor en diferentes cálculos.
Fuente consultada: Elaboración propia.

8. Tipo de dato
Definición: El tipo de dato indica qué clase de información se está almacenando, como números, texto o valores verdaderos y falsos.
Ejemplo: 25 puede ser un número entero, "Luis" es texto y True representa un valor verdadero.
Fuente consultada: Elaboración propia.

9. Operador
Definición: Un operador es un símbolo o palabra que permite realizar una operación sobre uno o varios datos.
Ejemplo: En 10 + 5, el símbolo + es un operador que sirve para sumar los dos números.
Fuente consultada: Elaboración propia.

10. Expresión
Definición: Una expresión es una combinación de valores, variables y operadores que puede producir un resultado.
Ejemplo: edad + 1 es una expresión porque utiliza una variable y un operador para obtener un nuevo valor.
Fuente consultada: Elaboración propia.

11. Condicional
Definición: Un condicional permite que un programa tome una decisión dependiendo de si una determinada condición se cumple o no.
Ejemplo: Si la edad de una persona es igual o mayor a 18, el programa puede mostrar “Eres mayor de edad”; de lo contrario, puede mostrar “Eres menor de edad”.
Fuente consultada: Elaboración propia.

12. Bucle
Definición: Un bucle es una estructura que permite repetir una o varias instrucciones varias veces sin tener que escribirlas nuevamente.
Ejemplo: Un programa puede utilizar un bucle para mostrar en pantalla los números del 1 al 10.
Fuente consultada: Elaboración propia.

13. Función
Definición: Una función es un bloque de instrucciones creado para realizar una tarea específica y que puede utilizarse cada vez que sea necesario.
Ejemplo: Una función llamada saludar() podría encargarse de mostrar el mensaje “Hola”.
Fuente consultada: Elaboración propia.

14. Parámetro
Definición: Un parámetro es una variable que se coloca en la definición de una función para indicar qué información puede recibir.
Ejemplo: En saludar(nombre), nombre es un parámetro porque indica que la función espera recibir un nombre.
Fuente consultada: Elaboración propia.

15. Argumento
Definición: Un argumento es el valor que se proporciona a una función cuando se utiliza, para que esta pueda trabajar con ese dato.
Ejemplo: Si tenemos saludar(nombre) y escribimos saludar("Luis"), "Luis" es el argumento que se envía a la función.
Fuente consultada: Elaboración propia.

16. Retorno
Definición: El retorno es el resultado que una función puede devolver al lugar desde donde fue llamada.
Ejemplo: Una función que suma dos números puede recibir 5 y 3 y retornar el resultado 8.
Fuente consultada: Elaboración propia.

17. Arreglo
Definición: Un arreglo es una estructura que permite guardar varios datos relacionados dentro de una misma colección y acceder a ellos mediante posiciones o índices.
Ejemplo: Un arreglo llamado frutas podría almacenar "manzana", "plátano" y "naranja".
Fuente consultada: Elaboración propia.

18. Objeto
Definición: Un objeto es una estructura que permite reunir información y acciones relacionadas dentro de una misma entidad. Puede representar algo del mundo real o una idea dentro de un programa.
Ejemplo: Un objeto Persona podría tener datos como nombre y edad, además de acciones como saludar().
Fuente consultada: Elaboración propia.

19. Método
Definición: Un método es una función que pertenece a un objeto o a una clase y que sirve para realizar una acción relacionada con ese objeto.
Ejemplo: Si tenemos un objeto Persona, un método llamado saludar() podría utilizarse para hacer que esa persona muestre un saludo.
Fuente consultada: Elaboración propia.

20. Evento
Definición: Un evento es una acción o situación que ocurre durante la ejecución de un programa y que puede provocar que se ejecute determinado código.
Ejemplo: En una página web, cuando el usuario hace clic en un botón, ese clic puede funcionar como evento para ejecutar una acción.
Fuente consultada: Elaboración propia.

21. Compilador
Definición: Es un programa que toma instrucciones escritas en un lenguaje de programación y las transforma a otra forma que la computadora puede ejecutar. Además, durante este proceso puede detectar errores.
Ejemplo: Al escribir un programa en C y ejecutarlo con GCC, el compilador transforma el código fuente en un programa ejecutable.
Fuente consultada: IBM, “¿Qué es un compilador?”; Oracle, documentación de Java sobre compilación.

22. Intérprete
Definición: Es un componente que lee instrucciones de un programa y las ejecuta durante la ejecución, en lugar de producir necesariamente un archivo ejecutable independiente antes de comenzar.
Ejemplo: Un intérprete puede leer instrucciones de un programa y realizar las operaciones conforme el programa avanza.
Fuente consultada: Oracle, “Glossary of Terms”, definición de interpreter.

23. Depurador (Debugger)
Definición: Es una herramienta que permite detener un programa, avanzar paso a paso en su ejecución y observar sus valores y estados internos para encontrar dónde ocurre un problema.
Ejemplo: Si una variable debería contener 100 pero aparece con 10, el programador puede colocar un punto de interrupción y revisar paso a paso dónde cambió el valor.
Fuente consultada: MDN Web Docs, “debugger” y “Developer tools”.

24. IDE
Definición: Un IDE, o entorno de desarrollo integrado, es una aplicación que reúne en un mismo lugar varias herramientas para programar, como editor, ejecución, compilación, pruebas y depuración.
Ejemplo: Visual Studio puede utilizarse para escribir código, compilarlo, depurarlo y probarlo sin tener que cambiar constantemente entre diferentes programas.
Fuente consultada: Microsoft Learn, “Visual Studio IDE”; MDN Web Docs, “IDE”.

25. Editor de código
Definición: Es un programa especializado en escribir y modificar código fuente. Puede ofrecer herramientas como resaltado de sintaxis, autocompletado, búsqueda y organización de archivos.
Ejemplo: Visual Studio Code permite editar archivos de diferentes lenguajes y también puede conectarse con herramientas de ejecución, depuración y control de código.
Fuente consultada: Visual Studio Code Documentation, “Core editor features” y “Get started”.

26. Biblioteca (Library)
Definición: Es un conjunto de código reutilizable que proporciona funciones o componentes preparados para resolver tareas comunes. Esto permite que el desarrollador no tenga que programar todo desde cero.
Ejemplo: Una biblioteca puede proporcionar funciones para trabajar con fechas, hacer peticiones a un servicio o manipular datos.
Fuente consultada: MDN Web Docs, “Introduction to client-side frameworks”; Oracle, documentación de Java sobre APIs y bibliotecas.

27. Framework
Definición: Es una estructura de trabajo que ofrece reglas, herramientas y una forma organizada de construir una aplicación. A diferencia de una biblioteca, un framework suele establecer una parte importante de la organización del proyecto.
Ejemplo: Al desarrollar una aplicación web con un framework, el proyecto puede seguir una estructura definida para organizar componentes, rutas y lógica.
Fuente consultada: MDN Web Docs, “Introduction to client-side frameworks”.

28. API
Definición: Una API es una forma definida para que un programa pueda solicitar funciones o datos a otro programa o componente. Establece reglas sobre qué se puede solicitar y cómo hacerlo.
Ejemplo: Una página web puede utilizar una API de geolocalización para solicitar la ubicación disponible del dispositivo y utilizarla para mostrar un mapa.
Fuente consultada: MDN Web Docs, “API - Glossary”.

29. Repositorio
Definición: Es un espacio donde se guarda un proyecto de software junto con la información necesaria para administrar sus archivos y, en sistemas como Git, su historial de cambios.
Ejemplo: Un proyecto de una página web puede tener un repositorio que contenga sus archivos HTML, CSS y JavaScript, además del historial de modificaciones.
Fuente consultada: MDN Web Docs, “Repo - Glossary”; GitHub Docs, documentación sobre repositorios.

30. Control de versiones
Definición: Es una forma de registrar y administrar los cambios realizados en los archivos de un proyecto. Permite consultar versiones anteriores, identificar cambios y facilitar el trabajo entre varias personas.
Ejemplo: Si una modificación rompe una aplicación, el equipo puede revisar el historial y recuperar una versión anterior que funcionaba correctamente.
Fuente consultada: Git Documentation, descripción de Git como sistema de control de revisiones; GitHub Docs.

31. Git
Definición: Es un sistema distribuido de control de versiones que permite guardar el historial de un proyecto, trabajar con diferentes líneas de desarrollo y combinar cambios.
Ejemplo: Un estudiante puede usar Git para registrar cada avance de un proyecto mediante commits y después consultar cómo estaba el código antes de una modificación.
Fuente consultada: Git Documentation, “git”.

32. GitHub
Definición: Es una plataforma que permite alojar y colaborar en proyectos de software utilizando Git. Además de almacenar código, ofrece herramientas para revisar cambios y administrar proyectos.
Ejemplo: Un equipo puede subir su repositorio a GitHub, crear una rama para una nueva función y solicitar que otro integrante revise los cambios.
Fuente consultada: GitHub Docs, “¿Qué es GitHub?” y documentación de GitHub sobre Git.

33. Rama (Branch)
Definición: Es una línea independiente de trabajo dentro de un repositorio. Permite desarrollar cambios sin modificar directamente la línea principal hasta que se decida integrarlos.
Ejemplo: Para agregar un formulario de registro, un programador puede crear una rama llamada formulario-registro, trabajar en ella y después integrar el resultado con la rama principal.
Fuente consultada: GitHub Docs, documentación sobre ramas y fusiones.

34. Commit
Definición: Es un registro de cambios guardado en el historial de Git. Permite identificar qué se modificó y cuándo se registró el cambio.
Ejemplo: Después de corregir un error en el inicio de sesión, el programador puede crear un commit con un mensaje como “Corregir validación del usuario”.
Fuente consultada: GitHub Docs, “Commits”.

35. Merge
Definición: Es la operación de integrar los cambios de una rama con otra. Se utiliza para reunir diferentes líneas de trabajo cuando están listas para formar parte del mismo proyecto.
Ejemplo: Después de terminar una nueva función en una rama, se puede hacer un merge hacia la rama principal para incorporar esa función al proyecto.
Fuente consultada: GitHub Docs, “Getting changes from a remote repository” y “Pull request merges”.

36. Callback
Definición: Es una función que se entrega a otra función para que pueda ser ejecutada posteriormente, normalmente cuando ocurre un evento o termina una operación.
Ejemplo: Una función puede recibir un callback para indicar qué debe hacerse después de obtener una respuesta de un servidor, como mostrar los datos en pantalla.
Fuente consultada: MDN Web Docs, “Introducing asynchronous JavaScript”, sección “Callbacks”.

37. Programación síncrona
Definición: Es una forma de ejecución en la que una operación debe terminar o avanzar antes de que el flujo continúe con la siguiente. Si una tarea tarda, las instrucciones posteriores esperan.
Ejemplo: Si un programa realiza una operación que tarda varios segundos de manera síncrona, el resto del flujo puede quedar detenido hasta que esa operación termine.
Fuente consultada: MDN Web Docs, “Synchronous” y “Synchronous and asynchronous requests”.

38. Programación asíncrona
Definición: Es una forma de organizar tareas para que una operación que puede tardar no tenga que bloquear todo el flujo mientras termina. Cuando el resultado está disponible, el programa puede continuar mediante mecanismos como callbacks, promesas o async/await.
Ejemplo: Una página puede solicitar información a un servidor y seguir respondiendo a la interacción del usuario mientras espera la respuesta. Cuando llega, puede actualizar la información mostrada.
Fuente consultada: MDN Web Docs, “Introducing asynchronous JavaScript” y “Synchronous and asynchronous requests”.

39. JavaScript
Definición: Es un lenguaje de programación utilizado principalmente para agregar comportamiento e interactividad a las páginas web, aunque también puede ejecutarse en servidores y otros entornos.
Ejemplo: Con JavaScript se puede programar un botón para que, al hacer clic, cambie el contenido de una página sin tener que recargarla por completo.
Fuente consultada: MDN Web Docs, “JavaScript”, “What is JavaScript?” y “JavaScript technologies overview”.

40. TypeScript
Definición: Es un lenguaje basado en JavaScript que agrega un sistema de tipos para ayudar a detectar ciertos errores antes de ejecutar el programa. El código TypeScript puede transformarse posteriormente en JavaScript para ejecutarse en entornos compatibles.
Ejemplo: Si una función espera recibir un número y el programador intenta pasarle un texto, TypeScript puede señalar el problema durante la comprobación del código antes de ejecutar la aplicación.
Fuente consultada: TypeScript Handbook, “TypeScript for the New Programmer” y “The TypeScript Handbook”.
